# SAT Trainer

Интерактивный тренажёр из PDF-экспорта [College Board Educator Question Bank](https://satsuiteeducatorquestionbank.collegeboard.org/).

Загрузите PDF — и решайте вопросы как в нормальном приложении:

- **сначала слова, потом вопрос**: вопрос открывается, когда выучены слова из его вариантов ответа (в Words in Context — все четыре варианта, в остальных — трудные слова вариантов). Тренажёр показывает эти слова с определениями и примерами, проверяет их (слово → выбрать значение) и только потом открывает вопрос — отвечать, не зная, что значат варианты, это угадывание. Если слову пришло время повторения, вопрос снова ждёт, пока слово не вспомнят (так и при повторе ошибок); фильтр «Слова выучены» — вопросы, к которым все слова уже знакомы;
- клик по варианту сразу показывает, верно или нет, и открывает разбор;
- разбор разложен по вариантам A–D;
- вычёркивание вариантов (как Answer Eliminator в Bluebook);
- **несколько PDF в одном тренажёре**: «Добавить ещё PDF» объединяет новые вопросы с уже загруженными (без дублей, номера старых вопросов не меняются), прогресс общий;
- фильтры по навыкам (сгруппированы по доменам), сложности и статусу: «повторить», «не решены», «ошибки», «верно», «отмеченные»;
- статистика точности по каждому навыку;
- **время на вопрос**: у каждого вопроса своя норма по длине текста (короткий Words in Context около 0:50, два текста около 1:50; в сумме модуль — 32 минуты, как на SAT). Пока решаете, таймер скрыт, время считается; после ответа видно время и норму, а ошибка намного быстрее нормы помечается как «похоже на спешку». Таймер можно показать в настройках на экране «Сегодня»;
- **вопросы с графиком или таблицей**: картинкой из PDF остаётся только сам график, текст и варианты обычные, варианты можно вычёркивать;
- переключатель «оригинал PDF» для сверки с исходной вёрсткой;
- **четыре блока SAT и их навыки**: переключение между Craft and Structure, Information and Ideas, Standard English Conventions и Expression of Ideas и их навыками, с прогрессом по каждому; блок без вопросов подсказывает, как добавить его PDF;
- **«сначала сами» в Words in Context**: варианты открываются, когда вы отметили в тексте слово-подсказку (если оно есть в предложении с пропуском) и написали своё слово; в «most nearly mean» слово закрыто, пока вы не предложите замену. В Transitions сначала выбираете связь между предложениями, и тренажёр её проверяет; в Command of Evidence и Inferences пишете, что должен показать ответ. На экране «Сегодня» видно, как изменилась точность;
- **словарь**: карточки с интервальными повторениями — слова из вариантов ответа и из текстов, по порядку вопросов: сначала слова, которые откроют следующие вопросы. Новое слово сначала просто показывается — значение и простой пример, — а через несколько карточек его нужно вспомнить. Слово, которое вы уже видели, вы вспоминаете сами, открываете карточку и отмечаете факт, а не степень: «Вспомнил» (→) или «Не вспомнил» (←). Вспомнили — дальше по графику (новое — завтра); не вспомнили — слово вернётся через несколько карточек и завтра (незнание ещё не выученного слова не сокращает его будущие интервалы). Значения из словаря в проверке перед вопросом приводятся к виду собственных: без части речи, одно значение, той же длины. Три «Вспомнил» подряд в разные дни — слово выучено и дальше возвращается раз в 2–3 недели; забытое снова становится «изучаю». Определения и примеры на английском написаны для тренажёра (`assets/data/defs.txt`), без привязки к конкретному вопросу: значение — словами проще самого слова, без фразовых глаголов («put out», «take back»), и у каждого слова свой короткий простой пример, который показывается раньше предложения из вопроса (`tests/defs.test.js` следит за этим). Пока вопрос не решён, карточка не показывает его текст, номер и роль слова; значение слова из вопроса «what does the word X mean» откроется после ответа. Любое слово можно добавить, выделив его в тексте вопроса — определение подтянется из Wiktionary;
- **ассистент Claude** (в версии на claude.ai): чат про открытый вопрос или слово — подсказки без спойлеров, перевод, разбор ошибок, похожие вопросы; «Объяснить» для выделенного слова; история переписки по каждому вопросу;
- **повтор ошибок по расписанию**: неверно решённый вопрос возвращается через 1, 3 и 7 дней и показывается заново; три верных ответа подряд — ошибка закреплена;
- **пробник** (на экране «Сегодня»): Reading and Writing как на SAT — два модуля по 27 вопросов и 32 минуты, блоки в порядке экзамена, внутри блока по типу и от лёгких к трудным; второй модуль труднее, если в первом верно две трети и больше, иначе полегче. Вопросы — сначала нерешённые, если не хватает — решённые давно. Без проверки слов, «сначала сами» и разборов; можно ходить по вопросам модуля, отмечать и вычёркивать варианты; модуль закрывается сам, когда время вышло. В конце — диапазон балла из 800 по официальной таблице College Board («Scoring Your SAT Practice Test #7»: верные → из 66 → диапазон; на пробнике Bluebook с 40 из 54 даёт 580–640 при настоящих 630), разбор по типам (верно, в спешке, дольше нормы) и ошибки, которые уже в повторе. История пробников хранится в аккаунте;
- **«Сегодня»**: план дня (повторы, карточки, новые вопросы), серия закрытых дней, календарь активности, достижения, напоминание в Календарь;
- **тест словарного запаса** (Словарь → «Мой уровень английского», ~5 минут): «знаю / не знаю» для слов из 12 полос частоты и выдуманных слов, которые ловят угадывание. Показывает, сколько из ~18 тысяч самых частых слов вы знаете и какая доля слов обычного текста вам знакома, и выставляет уровень «По тесту» — трудными считаются слова реже вашей границы;
- **трудные слова в текстах**: в тексте вопроса подчёркнуты слова реже выбранного уровня английского; нажатие — определение; слова текстов попадают в карточки по порядку вопросов;
- **аккаунт**: «Войти через Google» — ответы, карточки, ошибки на повтор, активность и сами вопросы (PDF) сохраняются в вашем аккаунте и появляются на каждом устройстве, где вы вошли. Без входа всё хранится только на устройстве;
- резервная копия в файл — прогресс, словарь, повторы, переписка и PDF с вопросами: одного файла хватит, чтобы перенести всё на телефон («Перенести прогресс с другого устройства» на стартовой странице);
- светлая и тёмная тема, работает на телефоне;
- горячие клавиши: `A`–`D` ответ, `Shift`+`A`–`D` вычеркнуть, `←` `→` навигация, `E` разбор, `F` отметить, `O` оригинал.

## Как пользоваться

1. Откройте Educator Question Bank, выберите тест, раздел, домены и сложность, отметьте вопросы.
2. **Export → With correct answers and explanations → Download PDF**.
3. Перетащите PDF на страницу тренажёра. Следующие экспорты добавляйте так же — вопросы соберутся в одну базу.

## Приватность

PDF разбирается прямо в браузере с помощью [pdf.js](https://mozilla.github.io/pdf.js/) — файл никуда не отправляется.
Без входа единственный внешний запрос — поиск определения в Wiktionary для слова, которого нет в словаре тренажёра; туда уходит только само слово.
Если войти через Google, ответы, словарь, повторы, активность и загруженные PDF хранятся ещё и в Firestore (Firebase) в папке `users/<ваш id>`; правила базы разрешают читать и писать её только вам. Переписка с ассистентом в аккаунт не уходит.

Частоты слов — [wordfreq](https://github.com/rspeer/wordfreq) (Robyn Speer), CC BY-SA 4.0: `assets/data/en-zipf.txt`, собирается `scripts/build_wordfreq.py`. Определения слов написаны для тренажёра: `assets/data/defs.txt` (строка `слово|часть речи|определение|пример`); для остальных слов — [Wiktionary](https://en.wiktionary.org), CC BY-SA.
Вопросы, PDF и прогресс хранятся на устройстве (IndexedDB и localStorage) и, после входа, в аккаунте студента. В репозитории нет материалов College Board.

## Как это устроено

Без сборки: статический `index.html` + ES-модули.

- `assets/parser.js` — разбирает экспорт: находит вопросы, варианты, правильный ответ и разбор; восстанавливает абзацы, стихи, курсив (по наклону глифов), подчёркивания, верхние и нижние индексы.
- `assets/app.js` — интерфейс тренажёра.
- `assets/vocab.js` — колода слов из Words in Context, интервальные повторения (SM-2), поиск определений в Wiktionary.
- `assets/prep.js` — «сначала слова»: экран слов из вариантов ответа и проверка перед вопросом.
- `assets/vocab-ui.js` — экраны словаря: карточки, список, добавление слова из текста.
- `assets/size-test.js` — тест словарного запаса; данные — `assets/data/vocab-test.json` (базовые слова, ранжированные по частоте wordfreq; выборки слов из каждой полосы без имён и сленга; выдуманные слова, которых нет в словаре частот).
- `assets/domains.js` — четыре блока Reading and Writing, их навыки и прогресс по ним.
- `assets/think.js` — шаги «сначала сами»: слова-сигналы, связи переходов и порядок шагов.
- `assets/figure.js` — график или таблица отдельно от текста вопроса и вид PDF одним блоком.
- `assets/obvious-words.js` — слова, которые редки, но не требуют заучивания: числительные, понятные составные слова.
- `assets/words.js` — трудные слова в текстах и вариантах ответа по частотному словарю, начальные формы слов, словарь определений.
- `assets/timer.js` — честный таймер на вопрос (пауза при уходе со вкладки, из приложения или при бездействии).
- `assets/today.js` — расписание повторов ошибок, план дня, серия, календарь активности, достижения.
- `assets/merge.js`, `assets/sync.js` — трёхстороннее слияние данных устройства и аккаунта (последняя согласованная копия — база, поэтому удаления и сброс тоже переносятся) и движок синхронизации по разделам.
- `assets/account.js`, `assets/cloud.js`, `assets/cloud-config.js` — вход через Google, правила слияния каждого раздела, PDF в аккаунте кусками по 900 КБ; Firebase SDK грузится с gstatic.com, только когда это нужно: открыто меню или стартовая страница (чтобы окно входа открылось сразу по нажатию) или устройство уже входило. Правила Firestore: `match /users/{uid}/{document=**} { allow read, write: if request.auth != null && request.auth.uid == uid; }`.
- `assets/bytes.js` — PDF в base64 для файла прогресса.
- `assets/assistant.js` — ассистент Claude: работает, только когда страница открыта как артефакт на claude.ai (через аккаунт зрителя); на GitHub Pages скрыт.
- `artifact.html` — та же страница в формате артефакта claude.ai.
- `assets/styles.css` — дизайн-система (светлая и тёмная тема).

Перед выпуском обновления: `python3 scripts/stamp.py` — проставляет новую версию в ссылки на файлы (GitHub Pages разрешает браузерам кэшировать их 10 минут), а открытый сайт сам перезагрузится, увидев новую версию в `version.json`.

Локальный запуск:

```bash
python3 -m http.server 8000
```

Тесты (`tests/`) открываются в браузере по `/tests/` или в headless Chrome: `scripts/test.sh http://localhost:8000/tests/`.
