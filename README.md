# SAT Trainer

Интерактивный тренажёр из PDF-экспорта [College Board Educator Question Bank](https://satsuiteeducatorquestionbank.collegeboard.org/).

Загрузите PDF — и решайте вопросы как в нормальном приложении:

- **сначала слова, потом вопрос**: вопрос открывается, когда выучены слова из его вариантов ответа (в Words in Context — все четыре варианта, в остальных — трудные слова вариантов). Тренажёр показывает эти слова с определениями и примерами, проверяет их (слово → выбрать значение) и только потом открывает вопрос — отвечать, не зная, что значат варианты, это угадывание. Фильтр «Слова выучены» — вопросы, к которым все слова уже знакомы;
- клик по варианту сразу показывает, верно или нет, и открывает разбор;
- разбор разложен по вариантам A–D;
- вычёркивание вариантов (как Answer Eliminator в Bluebook);
- **несколько PDF в одном тренажёре**: «Добавить ещё PDF» объединяет новые вопросы с уже загруженными (без дублей, номера старых вопросов не меняются), прогресс общий;
- фильтры по навыкам (сгруппированы по доменам), сложности и статусу: «повторить», «не решены», «ошибки», «верно», «отмеченные»;
- статистика точности по каждому навыку;
- **время на вопрос**: таймер идёт только пока вопрос открыт и не отвечен, вкладка активна и есть действия (3 минуты без действий — пауза); после ответа видно своё время, среднее и темп SAT (1:11 на вопрос в Reading and Writing);
- переключатель «оригинал PDF» для сверки с исходной вёрсткой;
- **словарь**: карточки с интервальными повторениями — слова из вариантов ответа и из текстов, по порядку вопросов: сначала слова, которые откроют следующие вопросы. Определения и примеры на английском написаны для тренажёра (`assets/data/defs.txt`), без привязки к конкретному вопросу. Пока вопрос не решён, карточка не показывает его текст, номер и роль слова; значение слова из вопроса «what does the word X mean» откроется после ответа. Любое слово можно добавить, выделив его в тексте вопроса — определение подтянется из Wiktionary;
- **ассистент Claude** (в версии на claude.ai): чат про открытый вопрос или слово — подсказки без спойлеров, перевод, разбор ошибок, похожие вопросы; «Объяснить» для выделенного слова; история переписки по каждому вопросу;
- **повтор ошибок по расписанию**: неверно решённый вопрос возвращается через 1, 3 и 7 дней и показывается заново; три верных ответа подряд — ошибка закреплена;
- **«Сегодня»**: план дня (повторы, карточки, новые вопросы), серия закрытых дней, календарь активности, достижения, напоминание в Календарь;
- **трудные слова в текстах**: в тексте вопроса подчёркнуты слова реже выбранного уровня английского; нажатие — определение; слова текстов попадают в карточки по порядку вопросов;
- резервная копия прогресса, словаря, повторов и переписки в файл;
- светлая и тёмная тема, работает на телефоне;
- горячие клавиши: `A`–`D` ответ, `Shift`+`A`–`D` вычеркнуть, `←` `→` навигация, `E` разбор, `F` отметить, `O` оригинал.

## Как пользоваться

1. Откройте Educator Question Bank, выберите тест, раздел, домены и сложность, отметьте вопросы.
2. **Export → With correct answers and explanations → Download PDF**.
3. Перетащите PDF на страницу тренажёра. Следующие экспорты добавляйте так же — вопросы соберутся в одну базу.

## Приватность

PDF разбирается прямо в браузере с помощью [pdf.js](https://mozilla.github.io/pdf.js/) — файл никуда не отправляется.
Единственный внешний запрос — поиск определения в Wiktionary для слова, которого нет в словаре тренажёра; туда уходит только само слово.

Частоты слов — [wordfreq](https://github.com/rspeer/wordfreq) (Robyn Speer), CC BY-SA 4.0: `assets/data/en-zipf.txt`, собирается `scripts/build_wordfreq.py`. Определения слов написаны для тренажёра: `assets/data/defs.txt` (строка `слово|часть речи|определение|пример`); для остальных слов — [Wiktionary](https://en.wiktionary.org), CC BY-SA.
Вопросы, PDF и прогресс хранятся только локально (IndexedDB и localStorage). В репозитории нет материалов College Board.

## Как это устроено

Без сборки: статический `index.html` + ES-модули.

- `assets/parser.js` — разбирает экспорт: находит вопросы, варианты, правильный ответ и разбор; восстанавливает абзацы, стихи, курсив (по наклону глифов), подчёркивания, верхние и нижние индексы.
- `assets/app.js` — интерфейс тренажёра.
- `assets/vocab.js` — колода слов из Words in Context, интервальные повторения (SM-2), поиск определений в Wiktionary.
- `assets/prep.js` — «сначала слова»: экран слов из вариантов ответа и проверка перед вопросом.
- `assets/vocab-ui.js` — экраны словаря: карточки, список, добавление слова из текста.
- `assets/words.js` — трудные слова в текстах и вариантах ответа по частотному словарю, начальные формы слов, словарь определений.
- `assets/timer.js` — честный таймер на вопрос (пауза при уходе со вкладки, из приложения или при бездействии).
- `assets/today.js` — расписание повторов ошибок, план дня, серия, календарь активности, достижения.
- `assets/assistant.js` — ассистент Claude: работает, только когда страница открыта как артефакт на claude.ai (через аккаунт зрителя); на GitHub Pages скрыт.
- `artifact.html` — та же страница в формате артефакта claude.ai.
- `assets/styles.css` — дизайн-система (светлая и тёмная тема).

Перед выпуском обновления: `python3 scripts/stamp.py` — проставляет новую версию в ссылки на файлы (GitHub Pages разрешает браузерам кэшировать их 10 минут), а открытый сайт сам перезагрузится, увидев новую версию в `version.json`.

Локальный запуск:

```bash
python3 -m http.server 8000
```
